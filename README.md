# Ashray Designers & Consultants: Website

Static website (HTML5, CSS3, vanilla JS) hosted on GitHub Pages.

Live: https://www.ashraydesignersandconsultants.com

## Structure
- `index.html`, `projects.html`, `about.html`, `app.html`: the four pages
- `assets/css/style.css`: all styling (colours and fonts are CSS variables at the top)
- `assets/js/main.js`: projects filter
- `images/`: project photos (replace a file, keep the same name)
- `CNAME`: custom domain, do not delete

## Common edits
- Change text: open the page on GitHub, click the pencil icon, edit, commit.
- Add a project: copy one `<a data-c="...">` block in `projects.html`, add the photo to `images/`.
- AI assistant URL: set in `app.html` (`iframe src`).
